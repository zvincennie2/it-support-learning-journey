
# Troubleshooting Internet Connection Issues

## Problem
A computer cannot connect to the internet.

## Possible Causes
- Wi-Fi is turned off.
- The computer is connected to the wrong network.
- The router or modem has lost connectivity.
- The network adapter has a problem.
- The computer has an incorrect network configuration.

## Troubleshooting Steps

### Step 1: Check Wi-Fi
Confirm that Wi-Fi is enabled and airplane mode is turned off.

### Step 2: Check the Network
Make sure the computer is connected to the correct Wi-Fi network.

### Step 3: Restart the Connection
Disconnect from Wi-Fi, reconnect, and test the internet again.

### Step 4: Restart Network Equipment
If appropriate, restart the router or modem.

### Step 5: Test Another Device
Check whether another device can connect to the same network.

### Step 6: Escalate if Necessary
If the problem continues, document the results and escalate to the appropriate IT technician.

## Resolution
Document the cause of the problem and the steps that resolved it.
